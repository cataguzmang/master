## Workshop ML

Caso de negocio en retail usando el dataset Superstore. Cubre el ciclo completo de ML:

- **EDA** — análisis exploratorio y preparación de datos
- **Clasificación** — Logistic Regression vs Random Forest (pedidos rentables/no rentables)
- **Regresión** — Linear Regression vs Decision Tree (predicción de Profit)
- **No supervisado** — PCA + KMeans (segmentación de clientes)
- **Modelos avanzados** — Decision Tree → Random Forest → XGBoost + GridSearchCV
- **Explicabilidad** — SHAP (Summary, Waterfall, Dependence Plot)
