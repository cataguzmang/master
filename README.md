# Master — Materiales y Proyectos

Repositorio con los notebooks, ejercicios y proyectos del Máster en IA y Data Science.

## Estructura

```
📁 ArmorPlAI/          — Dashboard de prevención de lesiones deportivas con IA
   ├── app-mvp/        — Prototipo vanilla (HTML/CSS/JS)
   └── armorplay-mvp/  — MVP React + Vite + shadcn/ui

📁 Workshop/           — Workshop de Machine Learning integrado
   └── Workshop_ML.ipynb

```

## Proyectos

### ArmorPlAI
Sistema de análisis y prevención de lesiones deportivas. Incluye dos versiones: un prototipo en vanilla JS y un MVP completo en React/TypeScript con visualizaciones avanzadas (radar, sparklines, semáforo de riesgo).

### Workshop ML
Caso de negocio en retail usando el dataset Superstore. Cubre el ciclo completo de ML: EDA, clasificación, regresión, clustering, modelos avanzados (XGBoost) y explicabilidad con SHAP.

## Stack general
`Python` `scikit-learn` `XGBoost` `SHAP` · `React` `TypeScript` `Vite` `shadcn/ui`
