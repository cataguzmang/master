# Workshop — Machine Learning Integrado

Material del workshop de ML del Máster. Caso de negocio en retail usando el dataset Superstore.

## Contenido

- `Workshop_ML.ipynb` — Notebook principal del workshop

## Temario

| Módulo | Contenido |
|---|---|
| EDA | Análisis exploratorio y preparación de datos |
| Clasificación | Logistic Regression vs Random Forest (pedidos rentables/no rentables) |
| Regresión | Linear Regression vs Decision Tree (predicción de Profit) |
| No supervisado | PCA + KMeans (segmentación de clientes) |
| Modelos avanzados | Random Forest → XGBoost + GridSearchCV |
| Explicabilidad | SHAP (Summary, Waterfall, Dependence Plot) |

## Stack
`Python` `scikit-learn` `XGBoost` `SHAP` `pandas` `matplotlib` `seaborn`
