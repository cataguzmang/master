# ArmorPlAI — Dashboard de Prevención de Lesiones

Proyecto del Máster. Sistema de análisis y prevención de lesiones deportivas con inteligencia artificial.

## Versiones

### `app-mvp/` — Prototipo vanilla (HTML/CSS/JS)
Primera versión del dashboard. Interfaz funcional sin dependencias de framework.

- Login y autenticación
- Dashboard con KPIs de lesiones
- Gestión de jugadores y alineaciones
- Carga de datos vía Excel
- Reportes y historial
- Soporte i18n (ES/EN)

### `armorplay-mvp/` — MVP React + Vite
Versión productiva construida con React, TanStack Router y shadcn/ui.

- Arquitectura basada en rutas tipadas
- Componentes reutilizables (KpiCard, RadarChart, Sparkline, etc.)
- Sistema de semáforo de riesgo
- Contexto de autenticación y jugadores
- Mock data para demostración

## Stack
`HTML` `CSS` `JavaScript` · `React` `TypeScript` `Vite` `TanStack Router` `shadcn/ui`
